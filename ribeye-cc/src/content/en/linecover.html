Undergraduate project

linecover is the C++ implementation of my undergraduate project, “Highly efficient PCB copper pour coverage method.” It studies V-shaped brush paths to reduce coverage overlap and brush travel.

The project brings together the original command-line implementation and a browser-based interactive demonstration. See the research page for the method and original experimental results.

Interactive web demonstration

Open the PCB coverage interactive demo. Run it directly in your browser without installing an application.

  • Play both methods together, adjust the speed, step through strokes, or scrub the progress slider.
  • Generate random triangles or trapezoids, drag vertices, and change the minimum brush radius to compare results immediately.
  • Toggle corner-by-corner filling, stroke outlines, and the full travel trace, with solid drawing paths and dashed lifted transfers.
  • Compare coverage overlap and total travel, and save or load cases as JSON.

The web demonstration uses C++, raylib and WebAssembly, supporting triangles and convex trapezoids with horizontal bases. Its per-case geometry metrics are presented separately from the paper’s 1,000-triangle statistics.

Original implementation

The original linecover C++ project provides command-line execution, shape loading, random generation, method comparison and sample storage.
