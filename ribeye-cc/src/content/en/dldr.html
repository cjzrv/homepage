Overview

DLDR is a cross-platform desktop application to search, download, organize, and play purchased DLsite works, integrating a library manager, download queue, and audio player.

Features

  • Batch downloading, up to four parallel tasks, pause/resume, and bandwidth limiting.
  • Search and filtering by circle, voice actor, and genre, including exclusions and playlists.
  • Integrated player, synchronized VTT subtitles, and full-window script reading.
  • Shared Rust core serving a Tauri/Svelte GUI and CLI.

Architecture

Shared core
Rust handles library synchronization, search, the download queue, and data access.
Desktop and command line
Tauri and Svelte provide the desktop interface. The GUI and CLI share the same library and settings.
Local storage
SQLite stores library metadata, playlists, settings, and the download queue.
